# Функциональные требования

Предлагаемый объём первой версии. У каждого требования есть наблюдаемый результат, который можно проверить при демонстрации и тестировании.

## №1. Регистрация

Посетитель создаёт учётную запись по имени пользователя (нику), email и паролю. Повторная регистрация с тем же email или ником отклоняется с понятным сообщением. После регистрации пользователю автоматически назначается роль «Клиент» и создаётся пустая библиотека.

## №2. Вход и выход

Пользователь входит с корректными данными и выходит из кабинета. Неверные данные отклоняются с понятным сообщением. После выхода доступ к защищённым операциям (корзина, библиотека, вишлист, отзывы) требует повторного входа.

## №3. Разграничение доступа

Клиент видит и изменяет только свои данные: корзину, библиотеку, список желаемого, отзывы, профиль. Администратор управляет каталогом игр, жанрами, и пользователями. Проверка прав действует и при прямых запросах к API. При регистрации назначается только роль клиента; роль администратора выдаётся вручную.

## №4. Каталог игр

Любой посетитель открывает каталог и видит список опубликованных игр с обложкой, названием, жанрами, описанием и ценой. Неопубликованные игры в каталоге не отображаются.

## №5. Поиск и фильтрация в каталоге

Посетитель ищет игры по названию, фильтрует по жанру, диапазону цены и наличию скидки, сортирует по цене, дате выхода и популярности. Результаты соответствуют условиям; при отсутствии совпадений отображается сообщение «Ничего не найдено».

## №6. Страница игры

Посетитель открывает страницу игры и видит: название, описание, разработчика, издателя, дату выхода, жанры, скриншоты, системные требования (минимальные и рекомендуемые), цену, средний рейтинг и список отзывов. Кнопки «Купить» и «В список желаемого» доступны авторизованному пользователю.

## №7. Корзина

Авторизованный клиент добавляет игры в корзину и удаляет их. Одна и та же игра не добавляется дважды. В корзине отображаются: список игр, цена каждой позиции на момент добавления, итоговая сумма. Корзина сохраняется между входами. Игры, уже находящиеся в библиотеке клиента, повторно в корзину не добавляются с понятным сообщением.

## №8. Оформление заказа

Клиент оформляет заказ из корзины. В демонстрационном режиме оплата имитируется: проверяются сценарии «успех» и «ошибка». При успехе создаётся заказ со статусом «Оплачен», корзина очищается, а все игры заказа появляются в библиотеке клиента. При ошибке заказ не создаётся, корзина сохраняется, клиент может повторить попытку.

## №9. Библиотека

Клиент открывает библиотеку и видит только купленные им игры с датой покупки, временем в игре и датой последнего запуска. Игры, не купленные клиентом, в его библиотеке не отображаются. Библиотека сохраняется между входами.

## №10. Список желаемого

Клиент добавляет игры в список желаемого и удаляет их. Одна и та же игра не добавляется дважды. Купленные игры автоматически удаляются из списка желаемого. Список сохраняется между входами.

## №11. Отзывы и оценки

Клиент оставляет отзыв на игру только при наличии её в своей библиотеке: текст, рекомендация («рекомендую» / «не рекомендую»). Один клиент — один отзыв на игру; повторная отправка обновляет существующий. Отзывы клиентов, не купивших игру, отклоняются с понятным сообщением. Средний рейтинг игры пересчитывается автоматически.

## №12. Профиль пользователя

Клиент открывает свой профиль и видит: ник, аватар, количество игр в библиотеке, общее время в играх, свои отзывы и список желаемого. Клиент может изменить ник и аватар. Email изменить нельзя. Чужой профиль доступен только в публичной части (ник, аватар, публичные отзывы).

## №13. Управление играми (Модератор)

Модератор создаёт, редактирует, публикует и снимает с публикации игры. При создании указываются: название, описание, цена, дата выхода, разработчик, издатель, жанры, обложка, скриншоты, системные требования. Игра с неполными обязательными полями не сохраняется. Снятая с публикации игра исчезает из каталога, но остаётся в библиотеках купивших её клиентов.

## №14. Управление пользователями (администратор)

Администратор видит список пользователей, может заблокировать и разблокировать клиента, выдать или снять роль администратора. Заблокированный пользователь не может войти и совершать операции с понятным сообщением. Администратор не может заблокировать сам себя.

## №15. История заказов

Клиент видит список своих заказов: номер, дату, состав, сумму и статус. Новые заказы отображаются первыми. Заказ доступен для просмотра и после выхода и повторного входа. Клиент не может изменить состав или сумму уже оформленного заказа.

## №16. Подтверждение покупки

После успешного оформления заказа клиент показывает экран подтверждения с номером заказа, датой и временем, списком игр, суммой и статусом «Оплачен». Подтверждение доступно из истории заказов.

# Определения

- **Посетитель** — Неавторизованный пользователь. Может просматривать каталог и страницы игр. Не имеет корзины, библиотеки, профиля.
- **Пользователь** — Любой авторизованный аккаунт в системе. Общее понятие для всех ролей.
- **Клиент** — Пользователь с ролью «Клиент». Покупает игры, имеет корзину, библиотеку, вишлист, отзывы.
- **Модератор** — Пользователь с ролью «Модератор». Управляет каталогом: создаёт, редактирует, публикует игры, загружает скриншоты, заполняет системные требования. Не управляет пользователями.
- **Администратор** — Пользователь с ролью «Администратор». Управляет пользователями, ролями, имеет полный доступ.
- **Библиотека** — Набор игр, купленных конкретным клиентом.
- **Корзина** — Временный набор игр, выбранных клиентом для покупки.
- **Вишлист (список желаемого)** — Набор игр, которые клиент хочет купить в будущем.

# Объектно-ролевая модель

| Объект | Роль | Разрешения |
|---|---|---|
| Игра (Game) | Гость | Смотреть опубликованные |
| Игра (Game) | Клиент | Смотреть, купить (если не куплена) |
| Игра (Game) | Модератор | Создать, редактировать, публиковать, снять |
| Заказ (Order) | Клиент | Оформить, просматривать только свой |
| Корзина (Cart) | Клиент | Изменять только свою |
| Отзыв (Review) | Клиент | Создать только на купленную игру |
| Пользователь (User) | Администратор | Блокировать, менять роли (кроме себя) |
